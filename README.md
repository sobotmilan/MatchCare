# MatchCare
MatchCare predstavlja informacioni sistem namijenjen povezivanju roditelja i asistenata na brz, jednostavan i siguran način. Roditeljima je omogućen pronalazak pomoći u skladu sa potrebama njihove djece, dok je asistentima omogućeno predstavljanje sopstvenih kvalifikacija i efikasno pronalaženje zaposlenja.
